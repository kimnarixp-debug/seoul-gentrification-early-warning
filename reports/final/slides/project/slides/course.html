수업과의 연결

수업에서 배운 방법을 이렇게 썼다

수업 내용이 연구에서
데이터 분석 기초 · 표준화변수 7개의 표준화 방식 3가지(평균·표준편차, 중앙값, 순위)를 비교해 극단값에 끌려가지 않는 방식 선택
군집 분석 · 군집 수 결정k-means로 유형화, 실루엣·Calinski–Harabasz·Davies–Bouldin 지표로 3~8개를 비교해 5개로 결정
모델 평가2024년 4분기까지로 학습, 2025년 4분기로 평가하는 시간 분할 검증 · “유형 유지” 기준 모델과 비교 · AUC
프롬프트 · 시스템 프롬프트실험설계서와 CLAUDE.md 규칙 8개로 코드 생성기를 통제 (“알고리즘을 새로 구현하지 않는다”)
Tool UseAI 에이전트가 GitHub 저장소 설치, 함수 호출, 브라우저 자동화로 공공데이터 내려받기
에이전트 · 하네스단계마다 실행 → 검증 → 커밋 → 사람 확인 · 네트워크 우회 설치는 권한 단계에서 거부되어 사람이 판단 · 접속 허용 주소는 승인 후 추가
이 과정에는 수업에서 배운 내용이 두 층으로 들어갔습니다. 첫째는 분석 방법입니다. 변수 일곱 개의 단위가 달라서 표준화를 해야 했는데, 방식 세 가지를 비교해 극단값에 끌려가지 않는 방식을 골랐습니다. 몇 개의 유형으로 나눌지는 실루엣 같은 군집 평가 지표로 세 개에서 여덟 개까지 비교했습니다. 그리고 예측은 과거로 학습하고 미래로 평가하는 시간 분할 검증으로, “아무것도 안 바뀐다”는 기준 모델과 비교했습니다. 둘째는 도구입니다. 실험설계서를 프롬프트로, CLAUDE.md를 시스템 프롬프트로 써서 “알고리즘을 새로 만들지 말 것” 같은 규칙을 AI 에이전트에게 걸었습니다. 에이전트는 단계마다 실행, 검증, 커밋을 하고 제 확인을 받았습니다. 실제로 네트워크 차단을 우회하려는 설치는 권한 단계에서 거부됐고, 서울시 사이트 접속은 제가 승인한 뒤에야 열렸습니다. 수업에서 배운 하네스, 권한, 샌드박스가 그대로 작동한 셈입니다.
