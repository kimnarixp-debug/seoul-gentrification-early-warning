- 결과가 **원저자가 공개한 결과와 100% 일치**한다(겹치는 98,330행, 매출·점포 수·유동인구·전년 대비 증가율).
- **전 기간(21분기) 연속 관측 상권: 1,418개.** 설계서의 주제 전환 기준(500개 미만)을 넉넉히 넘는다.

## 1. 실행 방법
seoul_commerce의 `run_preprocessing()`과 같은 함수를 같은 순서로 부르고, 집객시설 자리에만 **행이 0개인 표**를 넣었다.
- seoul_commerce 코드가 스스로 `has_facilities=False`, 시설 수=결측으로 기록한다. 값을 지어내지 않는다.
- `external/` 코드는 고치지 않았다.
- 분석 범위는 seoul_commerce 설정 그대로: **2021년 1분기~2026년 1분기**, 외식업 10종(`CS100001`~`CS100010`).
  - 받은 자료에 있는 2026년 2분기는 이 설정에 따라 빠졌다.

```bash
cd external/seoul_commerce
uv run python ../../run/02_preprocess.py ../../data/raw/contract ../../data/processed/seoul_commerce
```
결과는 `data/processed/seoul_commerce/{english,korean}/`에 생긴다. 파일이 커서(최대 666MB) 저장소에는 올리지 않고, 위 명령으로 약 3분 만에 다시 만든다.

| 산출물 | 단위 | 행 수 |
|---|---|---|
| `trade_area_master.csv` | 상권 | 1,650 |
| `area_quarter.csv` | 분기 × 상권 | 34,650 |

1. 집객시설 없이 전처리했다(선택안 (나)). 우리 유형화 변수에는 영향이 없다.
